局域网键鼠共享 · 免 KVM 硬件

一套键盘、一只鼠标、
一份剪贴板

在同一局域网内的 Mac 与 Windows 之间共享。把光标推出屏幕边缘， 它就落到下一台机器上，键盘随之切换，剪贴板自动同步——不需要 KVM 硬件，也不用插线。

当前版本

macOS 版为免费自签名，首次打开请右键 → 打开。仅限可信局域网使用。

为什么选 MyKVM

软件即可用的 KVM：延迟低、配置少、开箱即用。

🖱️

跨屏切换

光标推出屏幕边缘即落到下一台机器，键盘自动跟随。按住 Alt（=Command）长按还能触发对端微信输入法语音。

📋

剪贴板同步

文本、图片、HTML、RTF 双向自动同步，复制即得，无需额外操作。

📁

文件拖拽

两端开启文件传输后，复制的文件或文件夹自动传到另一台电脑，在资源管理器或 Finder 直接粘贴（单个上限 2 GiB）。

🔒

加密直连

输入与剪贴板走 QUIC / TLS 1.3 加密连接，证书锁定对端，局域网内直连，不经任何中转服务器。

🖥️

多显示器布局

自动发现各机屏幕，拖拽排列让相邻边缘与桌面实际位置一致，多屏也能顺畅穿越。

🌏

双语双主题

中英文界面，浅色 / 深色 / 跟随系统主题，托盘常驻、开机自启。

界面预览

拖出屏幕边缘的那一刻，两台机器就成了一台。

快速开始

两台机器、几分钟、五步搞定。

两台机器都安装

从本页下载对应系统的安装包，Mac 和 Windows 各装一份。

选择角色

共享谁的键鼠，谁保持「服务端」（默认）；另一台在设置里切换为「客户端」。

建立连接

同一局域网自动发现。否则打开「设备」，输入对方 IP（可加端口）点添加。

排列屏幕

打开「布局」，拖动各显示器，让相邻边缘和实际桌面位置一致。

跨屏切换

把光标推出相邻边缘，它就切到另一台机器；键盘跟随，复制粘贴双向可用。

权限与须知

  • macOS（服务端）：在 系统设置 → 隐私与安全性 中授予「辅助功能」和「输入监控」，捕获与注入键鼠输入必需。更新后授权会保留；万一掉了，关掉再打开即可。
  • macOS 首次打开：版本为免费自签名（未经 Apple 公证），首次会被 Gatekeeper 拦截。右键应用 → 打开 → 打开，放行一次即可。
  • Windows：常规使用无需特殊权限；只有需要控制管理员窗口时才以管理员身份运行。
  • 安全边界：配对验证码与证书绑定已支持，但发现通道仍是明文。请勿把端口暴露到公网或不可信网络。
